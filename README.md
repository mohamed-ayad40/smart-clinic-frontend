# 🏥 Smart Clinic — Frontend UI Concept

## ⚠️ Project Status

This is a **frontend-only UI concept**. It was originally planned as a full-stack clinic management platform with a real AI/LLM-integrated assistant, developed with a small team. The backend was never built, and the team disbanded before the AI integration could be implemented. What remains is the complete, polished frontend — including a **mocked chat interface** that returns fixed sample responses to demonstrate the intended UX, not a live AI system.

---

## ✨ Features

- **Clinic Dashboard UI** — Patient records, appointment scheduling, and doctor views
- **AI Chat Interface (Mockup)** — A designed chat UI demonstrating the intended AI-assistant UX, using static mock responses (no live backend or LLM connection)
- **TypeScript** — Fully typed codebase for reliability and maintainability
- **Responsive UI** — Mobile-first design with Tailwind CSS

Next.js · TypeScript · Tailwind CSS
