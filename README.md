# 🏥 Smart Clinic — Frontend

A clinic management system frontend built with Next.js and TypeScript — handling patient appointments, doctor schedules, and medical records.

[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)](https://tailwindcss.com/)

**[🌐 Live Demo](https://smart-clinic-swart.vercel.app)**

</div>

---

## ✨ Features

- **Appointment Booking** — Patients can book, view, and cancel appointments
- **Doctor Dashboard** — Manage schedules and patient records
- **Admin Panel** — Oversee clinic operations and user management
- **TypeScript** — Fully typed codebase for reliability and maintainability
- **Responsive UI** — Mobile-first design with Tailwind CSS

---

## 🛠️ Tech Stack

Next.js · TypeScript · Tailwind CSS

---

## 🚀 Getting Started

```bash
git clone https://github.com/mohamed-ayad40/smart-clinic-frontend.git
cd smart-clinic-frontend
npm install
npm run dev
```
